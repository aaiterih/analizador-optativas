# User Journeys

**Fuente de datos:** El sistema extraerá la información analizando las [Guías Docentes de la universidad](../README.md).

## Journey de David
Es momento de hacer la matrícula. David entra a mirar las optativas y se da cuenta de que tiene que abrir un montón de PDFs de guías docentes para averiguar cómo evalúa cada una. Sabe que revisar todo eso le va a gastar mucho tiempo.
En lugar de ir abriendo los PDFs uno a uno, utiliza el analizador de optativas para comprobar directamente aquellas asignaturas que se aprueben casi enteras mediante evaluación continua.
El sistema le calcula al instante una lista con las opciones que mejor encajan con lo que necesita. Con esto, David apunta las asignaturas que más le interesan para matricularse.

## Journey de Laura
Llega el periodo de matrícula y Laura tiene que elegir sus optativas. Le agobia pensar en revisar cada guía en PDF para buscar si le piden presentaciones orales. 
En su lugar, entra al analizador de optativas para detectar y descartar las asignaturas que incluyen exposiciones en su evaluación. Así, obtiene al instante las opciones seguras y se matricula tranquila sabiendo que no tendrá que hablar en público.

Milestone 0: Modelo base de las optativas y evaluación
En este primer hito voy a entregar el primer módulo del programa que define la estructura básica de las asignaturas y sus reglas de evaluación (Objetivo 2). Básicamente, es la base para poder representar el problema en código.

Para saber si este producto es válido, el código tiene que poder ejecutarse en el lenguaje elegido y permitirme crear las asignaturas en memoria sin que salten errores. Si lo hace, significa que tengo la base lista y segura para poder añadirle los cálculos matemáticos después.

Milestone 1: Lógica de cálculo y comprobación automática
En este hito voy a entregar el módulo de código con la lógica principal del analizador de optativas (Objetivo 4). Este código se encarga de coger los datos de evaluación de las asignaturas y cruzarlos con las preferencias del estudiante para calcular una puntuación para cada opción.

Para comprobar que este producto es válido y funciona de verdad, lo entregaré junto con su infraestructura de pruebas. Sabré que es viable cuando los tests automáticos se ejecuten y pasen en verde, demostrando que el código calcula bien las puntuaciones para distintos tipos de alumnos sin fallos.
